# Аванс по договору

Отчёт на 10.11.2026: по каждой работе цена, выплачено и остаток, по каждому договору итог.

Запуск из корня репозитория:

```
python report.py --check
```

Команда строит отчёт и прогоняет контрольные даты. Файлы появятся в `out/`:

- `works.csv` - строка на каждую работу
- `contracts.csv` - итог по договору
- `skipped.csv` - платежи, которые в «выплачено» не вошли, и почему

Другая дата:

```
python report.py --date 2026-10-20
```

Нужен Python 3.11 или новее. Сторонние библиотеки не нужны.

Что смотреть:

- `report.py` - расчёт
- `DECISIONS.md` - решения там, где в выгрузке не было правила
- `accountant.md` - записка бухгалтеру
- `CURSOR_TRANSCRIPT.md` - ход работы
