# Записка бухгалтеру

Отчёт на 10.11.2026. В `works.csv` каждая работа, в `contracts.csv` итог договора. Суммы с точкой, столбцы через точку с запятой.

«Выплачено» - деньги, которые к этой дате уже ушли. «Осталось» - какая часть цены ими ещё не закрыта. «Долг» - остаток только по принятым работам. На 10.11 долг по обоим договорам ноль: всё принятое покрыто.

Платёж без номера работы разложен так: сначала закрыты принятые работы по дате приёмки, остаток аванса посажен на следующие запланированные. 15 000 за материалы остались на осенней съёмке.

В выплаченное не входят 150 000 в очереди по студии и 20 000, которые ушли Ивану 12.11. Ошибочные 50 000, возвращённые 10.09, в оплате ноль.

Проверьте, пожалуйста, три вещи: отменённая съёмка аксессуаров больше не оплачивается; упаковку на 10.11 считаем ещё не принятой, в файле приёмка стоит 11.11; такой порядок раскладки аванса вам подходит.
